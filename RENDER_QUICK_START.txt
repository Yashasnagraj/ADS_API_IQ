================================================================================
🔧 TROUBLESHOOTING
================================================================================

Backend "Exit 127" Error:
→ Check Start Command matches exactly (no extra spaces)
→ Root Directory is "api" (not "api/" or "/api")
→ Manual Deploy from Render dashboard

Database Not Found:
→ Check: git ls-files marketing_warehouse.db (should show file)
→ Verify: Build logs show "Database copied" or fallback message
→ DATABASE_URL is: sqlite:///./marketing_warehouse.db

Frontend Can't Connect:
→ Verify VITE_API_BASE_URL includes "/api/v1" at end
→ Check backend /health endpoint works first
→ Look for CORS errors in browser console (F12)

Cold Start (503):
→ Free tier sleeps after 15 min
→ First request takes 30-60 seconds
→ This is normal, wait and retry
