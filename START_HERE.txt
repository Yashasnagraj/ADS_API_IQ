API ENDPOINTS (All support customer filtering with ?customer_id=XXX):
--------------------------------------------------------------------------------

Customer Management:
  GET /api/customers                     - List all customers

Real-Time Metrics:
  GET /api/realtime/metrics              - Live metrics (last 24 hours)

Advanced KPIs:
  GET /api/kpi/roas                      - Return on Ad Spend
  GET /api/kpi/clv                       - Customer Lifetime Value
  GET /api/kpi/cac                       - Customer Acquisition Cost
  GET /api/kpi/quality-score             - Quality Score Impact
  GET /api/kpi/attribution               - Attribution Analysis
  GET /api/kpi/anomalies                 - Anomaly Detection
  GET /api/kpi/trends                    - Trend Analysis

Descriptive Analytics:
  GET /api/descriptive/kpis              - Current KPIs
  GET /api/descriptive/performance-trends - Historical trends
  GET /api/descriptive/channel-distribution - Channel performance

Diagnostic Analytics:
  GET /api/diagnostic/insights           - Performance insights
  GET /api/diagnostic/correlation-matrix - Metric correlations

Predictive Analytics:
  GET /api/predictive/forecasts          - Revenue forecasts
  GET /api/predictive/alerts             - Predictive alerts

Prescriptive Analytics:
  GET /api/prescriptive/recommendations  - Action recommendations
  GET /api/prescriptive/action-timeline  - Implementation timeline
