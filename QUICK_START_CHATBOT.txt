🚀 HOW TO START
─────────────────────────────────────────────────────────────────────────────────

OPTION 1: All-in-One (Recommended)
───────────────────────────────────
   Double-click: start_marketingiq_platform.bat

   This starts:
   ✓ SQLite Data API (port 8004)
   ✓ ADK Chatbot API (port 8003)
   ✓ React Dashboard (port 3000)


OPTION 2: Manual Start
───────────────────────
   Terminal 1:
   > python api_sqlite.py

   Terminal 2:
   > cd google-ads-multiagent\adk
   > python chatbot_api.py

   Terminal 3:
   > cd marketingiq-platform\web
   > npm start


💬 HOW TO USE THE CHATBOT
─────────────────────────────────────────────────────────────────────────────────

1. Open http://localhost:3000 in your browser

2. Click the chat icon (💬) in the bottom-right corner

3. Try these example queries:

   Campaign Performance:
   • "Show top performing campaigns"
   • "List my active campaigns"

   Keyword Analysis:
   • "What keywords are underperforming?"
   • "Show keyword quality scores"

   Budget Optimization:
   • "How should I optimize my budget?"
   • "Where should I spend more?"

   Performance Insights:
   • "Analyze my performance trends"
   • "Are there any issues with my campaigns?"

   Forecasting:
   • "Forecast next month's spend"
   • "Predict my CTR for next 30 days"


🔍 HOW IT WORKS
─────────────────────────────────────────────────────────────────────────────────

User Query
    ↓
React FloatingChatbot Component
    ↓
POST to http://localhost:8003/api/chat
    ↓
ADK Chatbot API (Intent Classification)
    ↓
Routes to appropriate ADK Agent:
  • Data Agent → Campaign/Keyword/AdGroup data
  • Insight Agent → Trends/Anomalies
  • Optimization Agent → Budget/Bid recommendations
  • Forecasting Agent → Performance predictions
    ↓
Agent queries SQLite Data API (port 8004)
    ↓
Response formatted in natural language
    ↓
Displayed in chat with markdown formatting

🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────────

❌ "Connection error" in chatbot:
   → Make sure chatbot API is running on port 8003
   → Check: http://localhost:8003/health

❌ "ADK agents not available":
   → Install google-adk: pip install google-adk
   → Check imports in chatbot_api.py

❌ No data in responses:
   → Ensure SQLite API is running on port 8004
   → Verify database has data: python check_db_schema.py
