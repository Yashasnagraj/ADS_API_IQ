  NETLIFY ENVIRONMENT VARIABLES - COPY & PASTE THIS
═══════════════════════════════════════════════════════════════

📍 WHERE: Netlify Dashboard → Site Settings → Environment Variables

Click "Add a variable" and add these TWO variables:

───────────────────────────────────────────────────────────────
VARIABLE 1: API URL (REQUIRED!)
───────────────────────────────────────────────────────────────

Key:
REACT_APP_API_URL

Value:
https://your-backend-url-here.railway.app/api/v1

⚠️ REPLACE "your-backend-url-here.railway.app" with your ACTUAL backend URL!

Example if using Railway:
https://ads-api-production.up.railway.app/api/v1

Example if using Render:
https://ads-api.onrender.com/api/v1

───────────────────────────────────────────────────────────────
VARIABLE 2: NODE VERSION (REQUIRED!)
───────────────────────────────────────────────────────────────

Key:
NODE_VERSION

Value:
18

───────────────────────────────────────────────────────────────
AFTER ADDING VARIABLES:
───────────────────────────────────────────────────────────────

1. Click "Save"
2. Go to "Deploys" tab
3. Click "Trigger deploy" → "Deploy site"
4. Wait 2-3 minutes
5. Your site is live! 🎉

───────────────────────────────────────────────────────────────
BACKEND NOT DEPLOYED YET?
───────────────────────────────────────────────────────────────

Deploy backend FIRST on Railway:

1. Go to: https://railway.app
