🚨 URGENT: UPDATE START COMMAND IN RENDER
================================================================================

The issue: uvicorn can't find the 'app' module because it's running from wrong dir

SOLUTION: Update Start Command to include 'cd api &&' prefix

================================================================================
GO TO RENDER DASHBOARD NOW
================================================================================

1. Go to: https://dashboard.render.com
2. Click your service: marketingiq-api
3. Click: Settings tab
4. Scroll to: "Build & Deploy" section
5. Find: "Start Command" field

6. CHANGE FROM:
   python -m uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-10000} --workers 2

7. CHANGE TO:
   cd /opt/render/project/src/api && python -m uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-10000} --workers 2

8. Click: "Save Changes" (at bottom)
9. Click: "Manual Deploy" → "Deploy latest commit"

================================================================================
COPY-PASTE THIS EXACT COMMAND:
================================================================================

cd /opt/render/project/src/api && python -m uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-10000} --workers 2

================================================================================
WHAT THIS DOES:
================================================================================

- cd /opt/render/project/src/api → Changes to api directory first
- && → Then runs uvicorn
- python -m uvicorn app.main:app → Starts the FastAPI app
- --host 0.0.0.0 → Binds to all interfaces
- --port ${PORT:-10000} → Uses Render's port (or 10000 default)
- --workers 2 → Runs 2 worker processes
